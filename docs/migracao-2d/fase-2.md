# Cena de sprites

PixiJS 8.22.0; GSAP 3.15.0; Lenis 1.3.27, versões locais fixas. Nenhum plugin de partículas ou filtro adicional: ParticleContainer nativo, brilho aditivo e texturas preparadas. Assets.load pré-carrega quatro folhas; falha WebP tenta JSON de PNG. AnimatedSprite com autoUpdate=false recebe quadros do relógio GSAP. Uma Application, sem ticker próprio ativo.

A integração nas páginas ocorre nas fases 4–5; a implementação anterior permanece até a validação e remoção na fase 6. Os scripts de captura são documentação de reprodução histórica, nunca carregados pelo aplicativo.
