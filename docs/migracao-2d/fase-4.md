# Viagem pelo scroll

Lenis sem autoRaf, chamado pelo ticker do GSAP que também desenha Pixi. ScrollTrigger controla uma timeline mestre: abertura, aproximação, um trecho por projeto, recuo final. Cada trecho tem um viewport de altura. Câmera transforma somente o Container mundo; estrelas e doze planetas seguem fatores próprios. No celular, cinco planetas e 690 estrelas preservam espaço para leitura. Reduced-motion dispensa Lenis e animação contínua.
